IT 接地架構入門 IT Grounding Fundamentals

為什麼數據中心必須做接地？三個核心原因。

1
突波保護
雷擊或開關突波需要一條低阻抗路徑洩放到大地，否則設備會被擊穿。
2
參考電位
所有設備共享同一零電位基準，訊號傳輸才不會因電位差而產生雜訊。
3
人身安全
故障電流導入大地，觸發保護裝置（斷路器/漏電斷路器）切斷電源。

五個關鍵術語

TMGB
Telecommunications Main Grounding Busbar
電信主接地匯流排
位於服務入口／MDA，整棟建築接地系統的根節點
TBB
Telecommunications Bonding Backbone
電信等電位主幹
平行電纜路徑佈設，連接各區域 TGB
TGB
Telecommunications Grounding Busbar
區域接地匯流排
設於各機房或機電區，匯集該區設備接地
BCT
Bonding Conductor for Telecommunications
設備接地導體
每台機櫃獨立接至最近 TGB，禁止串接
MESH-BN
Mesh Bonding Network
網狀等電位網絡
液冷機房地板下銅網，形成全面等電位面

四步施工順序

1
安裝 TMGB
在服務入口/MDA 安裝主接地匯流排，連接建築接地極與等電位連結
2
佈設 TBB
沿電纜路徑佈設等電位主幹，確保不與載流導體同管
3
架設網格
液冷機房鋪設地板下 MESH-BN 銅網，形成等電位面
4
逐櫃接地
每台機櫃獨立 BCT 接至最近 TGB，lug 端接、無 splice

三大禁忌：錯誤 vs 正確

❌ Daisy-Chain 串接

錯誤做法
機櫃1 → 機櫃2 → 機櫃3 串接，中間斷開則後方全部失去接地
正確做法
每櫃獨立 BCT 接至最近 TGB，單點故障不影響其他櫃

❌ TBB 內 Splice

錯誤做法
TBB 導體中間做接續（splice），增加接觸電阻與故障點
正確做法
TBB 全程無接續，只允許在 TMGB/TGB 匯流排端接

❌ 與載流導體同管

錯誤做法
TBB 與電力電纜穿同一管槽，電流變化感應雜訊至接地系統
正確做法
TBB 獨立佈設，平行於電纜路徑但物理隔離

接地電阻允收檢查表

  • 接地極系統總接地電阻 ≤ 1Ω
  • TMGB 至建築接地極 BCT 段建議 ≤ 0.1Ω
  • TGB 至 TMGB 電阻值 < 1Ω
  • 機櫃 BCT 至最近 TGB 電阻值 < 0.1Ω
  • 所有接地連接使用壓接 lug，無 splice
  • TBB 獨立佈設，不與載流導體同管
  • 每櫃獨立 BCT，禁止 daisy-chain
  • 液冷機房 MESH-BN 銅網多點焊接至 TGB
  • 等電位連結建築鋼構、水管、Ufer 接地
  • 施工順序：TMGB → TBB → 網格 → 逐櫃
